# Changelog

All notable changes to this project are documented here.

## [1.0.0]

Initial Codex-oriented release.

- Bilingual Polish and English humanization workflow.
- Language-aware routing with protected facts, numbers, URLs, citations, jargon, and author voice.
- Layered structural, linguistic, semantic, and mechanical QA.
- Original upstream examples and evaluation fixtures preserved.
- Optional local Bielik/Ollama review and advisory mode; suggestions are never applied automatically.
- Codex plugin and marketplace packaging with standalone skill support.
- Attribution preserved for `pielas-activy/humanizer-pl`, `blader/humanizer`, and the referenced source materials.
