# Code of Conduct

We want this project to be useful, welcoming, and technically focused.

Expected behavior includes respectful discussion, clear evidence when reporting a problem, and care with private text and user data. Harassment, discrimination, personal attacks, deliberate exposure of sensitive information, and malicious reports are not acceptable.

Maintainers may remove content or limit participation when needed to keep the project safe and constructive. For security concerns, follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue.
