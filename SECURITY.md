# Security policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. If it is not available, contact the maintainer through [the GitHub profile](https://github.com/mateuszkozlowski) and include only the minimum necessary details.

The project is primarily a local writing skill. Please report exposed secrets, unsafe installation behavior, path traversal, unintended network access, or processing of private text as security issues. Redact credentials and personal data from reports.

## Supported versions

Only the latest release on the `main` branch is actively maintained. Older versions may receive attention when a security fix is practical.
