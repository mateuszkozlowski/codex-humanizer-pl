# Support

For usage questions, installation help, and ideas, start a [GitHub Discussion](https://github.com/mateuszkozlowski/codex-humanizer-pl/discussions) when Discussions are enabled.

Use [GitHub Issues](https://github.com/mateuszkozlowski/codex-humanizer-pl/issues) for reproducible bugs and actionable feature requests. Please use a short redacted example and never paste private or confidential text.

Before asking for help, check the [README](README.md), [`references/setup-bielik.md`](references/setup-bielik.md), and the installed Codex/plugin version.
